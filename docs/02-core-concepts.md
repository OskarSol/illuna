# 02 · Core Concepts

## Core Building Blocks
- **Intent First**: Every interaction is interpreted as a potential intent.
- **Context Layer**: Time, place, history, and preferences provide meaning.
- **Adaptive Responses**: Outputs vary depending on situation and confidence.
- **Feedback Loop**: User feedback improves models and rules over time.

## Key Terms
- **Intent**: The goal a user is trying to achieve.
- **Signal**: Observable input (text, click, timing, etc.).
- **Profile**: Persistent preference and behavior patterns.
- **Session Context**: Short-term situational state during a session.
