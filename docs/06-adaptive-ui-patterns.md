# 06 · Adaptive UI Patterns

## Pattern Catalog (v1)
- **Progressive Disclosure**: Reveal complexity step by step.
- **Contextual Shortcuts**: Highlight frequent actions when relevant.
- **Confidence-aware UI**: Surface uncertainty in clear ways.
- **Mode Switching**: Shift between focus/explore modes by intent.

## UX Principles
- Adaptation must never feel like loss of control.
- Changes should remain consistent and explainable.
